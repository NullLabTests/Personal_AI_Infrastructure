# 03_Capital — Finances & Net Worth

**Purpose**: The resource layer. Tracks income, expenses, investments, budget variance, and net worth over time. Enables data-driven financial decisions.

### What goes here
- `Budget/` — Monthly budget CSVs with categories
- `Net-Worth/` — Quarterly net worth snapshots
- `Investments/` — Portfolio allocations, performance tracking
- `Expenses/` — Raw transaction exports (anonymized)
